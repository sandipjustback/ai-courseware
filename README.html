AI Courseware

Interactive courseware — agentic AI systems & enterprise architecture, a Software Architect prep track, and full System Design and Low-Level Design courses. A pure static SPA: no backend, no database; progress saves to localStorage.

Architecture

Contents

  • Track 1–3 — 9 agentic-AI modules (LangGraph, GraphRAG, memory, evals, RAG, MCP, iPaaS, capstone).
  • Q&A Bank — 50 concept/scenario/behavioral questions with answers.
  • Roles — Software Architect — study track + Q&A across senior-architect dimensions.
  • Course · System Design (HLD) — 7 modules.
  • Course · Low-Level Design (LLD) — 7 modules.

Run locally

npm install
npm run dev        # http://localhost:5173

Deploy to Vercel

  • Import the GitHub repo in Vercel.
  • Vercel auto-detects Vite (build npm run build, output dist; pinned in vercel.json).
  • No environment variables. Deploy.
